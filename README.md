## Overview

Terminal Layout is for keyboard users coming from Termius, Warp, tmux or Zellij. There is almost no chrome: your sessions fill the screen, split into panes, with one status line at the bottom. Hosts, tabs, actions and settings are all in the command palette.

Press Ctrl+Space, then a key like % to split right, " to split down, the arrows to move between panes or z to zoom. It works while a terminal has focus, and you can change the key in Settings, Keybindings. You can switch layouts in Settings, Appearance.

Read the [docs](https://docs.termix.site/plugins/terminal-layout) to learn how it works.

<br />

## Features

- Sessions fill the screen with almost no chrome
- Tiled panes like tmux or Zellij
- Ctrl+Space prefix keys to split, move, zoom, close and even out panes, and to switch tabs
- Command palette for hosts, open tabs, pane commands, plugin actions and settings
- Ctrl+Enter in the palette opens a host in a new pane
- One line status bar with numbered tabs and the focused host
- Start screen with your hosts when nothing is open
- Dashboard, Manage, Settings and the host editor from Classic Layout
- Phone view with a taller status bar

## Support

Bugs and ideas for Terminal Layout go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Terminal-Layout/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Terminal-Layout/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
